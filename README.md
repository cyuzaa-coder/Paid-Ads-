# Deploy with GitHub and Vercel

1. Create a GitHub repository and upload index.html and vercel.json to its root.
2. In Vercel, select Add New > Project and import that GitHub repository.
3. Use Framework Preset: Other, Root Directory: ./, no Build Command, and Output Directory: .
4. Click Deploy. Later pushes to the production branch will deploy automatically.

Redirect is disabled. The configured destination is https://cashapp-reward-halloween-2np1szkbf-cyuzaa-3860.vercel.app.
The existing clothing page is displayed when opened. Product cards retain their original placeholder links.

Vercel documentation: https://vercel.com/docs/builds/configure-a-build
